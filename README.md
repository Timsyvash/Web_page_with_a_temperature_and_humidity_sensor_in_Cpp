# Web Page with Temperature and Humidity Sensor in C++ (ESP8266 & DHT11)

Проєкт для збору показників температури та вологості з датчика **DHT11** за допомогою мікроконтролера **ESP8266 (Wemos D1 mini)** та виведення їх у реальному часі через HTTP вебсервер у локальній мережі.

---

## 🛠 Технології та Бібліотеки

* **Платформа:** ESP8266 (Arduino / PlatformIO)
* **Мережевий стек:** `ESP8266WiFi` (режим STA)
* **Вебсервер:** `ESP8266WebServer` (обробка HTTP GET запитів на різних маршрутах)
* **Датчик:** `DHT sensor library` для роботи з DHT11
* **Апаратна частина:** ESP8266 + датчик вологості та температури DHT11

---

## 📌 Підключення (Wiring)

| Пін ESP8266 (Wemos D1) | Пін датчика DHT11 | Опис |
| :--- | :--- | :--- |
| **3V3 або 5V** | VCC | Живлення датчика |
| **GND** | GND | Заземлення |
| **D2** | DATA (OUT) | Передача даних (цифровий пін) |

---
